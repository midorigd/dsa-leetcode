# DSA and LeetCode Solutions

These are my solutions to some common LeetCode questions, as well as various other problems from standard Data Structures and Algorithms topics.

This repository also includes my implementations of standard ADTs and algorithms from my DSA course in summer 2025.

## Topics

Topics covered include:

- Dynamic arrays
- Linear and binary search
- Selection, insertion, merge sort
- Stacks and queues
- Linked lists
- Binary trees and BSTs
- Hash maps

## Directories

**adts**: Implementations of common abstract data types  
**algos**: Implementations of common searching and sorting algorithms  
**solutions**: My solutions, organized by ADT

## Running a solution

Run the following from the project directory:

```zsh
python3 -m solutions.<category>.<solution-name>
```
